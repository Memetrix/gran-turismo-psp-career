# Provenance

Every part of the patch, where it comes from and under what terms. "Retail" means the unmodified commercial disc.
The build reads the retail game inputs below and the design written here. Its native controls, aspect bridge
and autoload wrapper are this project's own implementation; no other controls mod's code or binary is included.
The public export contains source, derived catalogs and published artwork. Original game executables, decrypted
ELFs, compiled PRXs, extracted volumes, raw databases, models, sound banks and private saves are not included.

Tools the build runs, not part of this repository, all by Nenkai (`docs/toolchain-refs.json` pins the commits of
GTAdhocToolchain and GTPSPVolTools):
[GTAdhocToolchain](https://github.com/Nenkai/GTAdhocToolchain) compiles the scripts,
[PDTools](https://github.com/Nenkai/PDTools) imports and exports SpecDB tables, and
[GTPSPVolTools](https://github.com/Nenkai/GTPSPVolTools) (MIT) unpacks and repacks `GT.VOL`. The packer is used with
two small changes (a fixed volume date for reproducible builds, and a compression cache); that diff is
`tools/gtpspvoltools-modifications.patch`, next to the tool's licence.

The native module builds with an existing PSP SDK. The SDK and its compiler are build dependencies, not bundled
source or a downloaded component of `build.py`. Native hooks are based on independently traced callsites in the
exact retail USA v2 executable. No claim of an unchanged executable applies to this integrated build: the
autoload wrapper produces a changed EBOOT and loads our own PRX from the disc image. Loader source and rollback
checks are public; the original and decrypted executable bytes stay local.

## Written in this repository

| File | What it holds |
| --- | --- |
| `scripts/career_event_design.py` | The career's own events: names, halls, entry rules, rival fields, courses, laps and prizes. Built from cars and courses available in the patched PSP game. |
| `design/parts-own-values.json` | For the 15 PSP cars the GT4 (USA) disc does not carry: the US car whose retail rows each one uses (for example the Vauxhall VX220 uses the Opel Speedster). Names only, no numbers. |
| `design/parts-psp-only.json` | Part ladders for the PSP-only cars GT4 has no rows for: stage, price and effect per part, in the scale of GT4's own rows. |
| `docs/audit-impl/D2-id-registry.json` | The id of every event in the save journal. |
| `design/native-parts-registry.json` | Which retail GT4 part row each car's shop offer uses, and the SpecDB row it becomes on the PSP. Generated from the retail rows and kept append-only because saves refer to it. |
| `design/career-gears.json`, `design/career-gears/` | Generated retail GT4 GEAR offers, row provenance and PSP factory references; small per-car setup files loaded on demand. Identical appended native payloads share a row; factory rows remain byte-identical. |

Every other file in `design/` is generated from the inputs above; `python3 scripts/check.py --generated` rebuilds
them and compares byte for byte.

read from the discs, *derived* adapts retail inputs to PSP templates, *generated* is rebuilt by `check.py --generated`,
*design* is written by hand here, and *art* is original or adapted artwork. For `design/new-cars/`, the origin describes
the car data definitions, not the source of their models; each file records its data source and PSP template.

## Art

The nine hall panels, menu icon, key art and original event flyers were made for this project with an image model,
using GT4 artwork as style or mood references. The published artwork also includes adaptations of original retail
GT4 pictures: thirty-five reworked covers in `design/art/event-art/cards/` are shared by sixty-four classic events
(see `cards-index.json`). These covers use GT4 pictures as their starting material. `design/art/preview-assets/`
also contains both original and adapted artwork. The interface chrome (`design/art/chrome/`) is drawn by
`scripts/bake_career_chrome.py`. Button, trophy and credit images that belong to the game are read from your own
disc during the build and are not in this repository.
