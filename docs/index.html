What does this page check?

It reads the file size and CRC32 locally. Delta Patcher then verifies the original image before applying the patch. Supported USA CRC32 values: 9613AC93, 1EADB6B4, and 71DCC467. If you choose an already patched ISO, it checks that it is the finished 1.0.0 image (CRC32 5FCB3D96).
