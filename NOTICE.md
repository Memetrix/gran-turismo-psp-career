# Credits and licences

Built with Nenkai's tools, with thanks to Nenkai and contributors: OpenAdhoc, the reconstructed source of GT PSP's own game scripts, which our changes are made in; GTAdhocToolchain, which compiles the scripts; and GTPSPVolTools, which packs the game volume. The complete source the patch is built from (the modified gameplay scripts, build scripts and data, with PROVENANCE.md and VERIFY.md) is supplied in the accompanying `Gran-Turismo-PSP-Career-v1.0.0-source.tar.gz` archive under GPL-3.0; this release bundle also includes the key art and patching scripts. See `LICENSE` and the retained notices in the source tree.

The patch bundle includes a modified build of Nenkai's GTPSPVolTools (MIT licence). Its licence and our source diff are in `tool-source/`, and the licence of every library in `tool/` is in `tool-source/licenses/`.

The 164 new career events, scripts, interface and packaging are project work. The 125 classic events recreate Gran Turismo 4's own event list.

The Ferrari 458 Italia's data and engine sound come from Gran Turismo 5. Its body is based on a model from Real Racing 3, reworked for the PSP. `PROVENANCE.md` in the source archive lists every source in detail.
