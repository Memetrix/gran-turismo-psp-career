# Changes to OpenAdhoc in Gran Turismo PSP Career 1.0.0

Gran Turismo PSP Career is built on [OpenAdhoc](https://github.com/Nenkai/OpenAdhoc), the reconstructed source of Gran Turismo PSP's game scripts by Nenkai and contributors, under GPL-3.0. This file lists what we changed, as GPL-3.0 section 5(a) asks.

- Upstream: OpenAdhoc commit `212cac08c01b4832234a120abcb47b4e693870d1`, folder `src/`.
- Ours: `src/adhoc/` in the source archive of the 1.0.0 release (`Gran-Turismo-PSP-Career-v1.0.0-source.tar.gz`), built from commit `1ded5f3c`.
- Full diff: [`openadhoc-212cac08-to-1.0.0.diff`](openadhoc-212cac08-to-1.0.0.diff) (`diff -ruN`, upstream as `a/`, ours as `b/`).

| File | Area |
| --- | --- |
| `projects/gt5m/arcade/arcade.ad`, `arcade.yaml` | career entry, new pages registered in the arcade project |

| `projects/gt5m/detail/CarDetailPopupImpl.ad` | car details with bought parts |
| `projects/gt5m/dialog/ConfirmDialog.ad` | button label |
| `projects/gt5m/race/ModuleArcade.ad`, `QuickArcadeRootImpl.ad` | race preparation with career rules and tuning |
